Each package is independently published to npm with zero runtime dependencies. Install just the types, the full SDK, or the standalone scoring engine — your call.

🧩

Type definitions

@opensam/sam-gov-types

Full TypeScript types for every endpoint of the SAM.gov Public API. Includes SamOpportunity, SamSearchParams, SamSearchResponse, and more.

  • Strict union types for notice & set-aside
  • JSDoc on every field
  • Matches SAM.gov's actual field names
🔌

HTTP SDK

@opensam/sdk

Fully typed HTTP client with retries, rate-limit handling, async iteration, and built-in scoring. Zero runtime deps — runs on Node, browsers, and edge runtimes.

  • Retry on 5xx, back off on 429
  • Auto-paginate with async generators
  • Static scoring method
📊

Scoring engine

@opensam/scoring

Deterministic viability score (0–100) using NAICS matching, set-aside alignment, capability keywords, and deadline proximity. No AI credits required.

  • Transparent, auditable formula
  • Reproducible scores
  • 119 lines of TypeScript
Developer experience

Type-safe from import to score

Full TypeScript everywhere. Autocomplete on every field of the SAM.gov response, including the oddly-named responseDeadLine (capital L — yes, really).

import { createClient } from '@opensam/sdk'

const sam = createClient({
  apiKey: process.env.SAM_GOV_API_KEY!,  // from api.data.gov
})

// Search active cloud-infrastructure solicitations
const results = await sam.search({
  query: 'cloud infrastructure',
  naicsCode: '541512',
  activeOnly: true,
  limit: 25,
})

// Score each against your company profile
const scored = await sam.searchAndScore(results.params, {
  naicsCodes: ['541511', '541512', '541519'],
  capabilities: ['software development', 'cloud infrastructure'],
  certifications: ['Small Business', 'SBA 8(a)'],
})

scored.forEach(({ opportunity, score, label }) => {
  console.log(`[${label.toUpperCase()} ${score}/100] ${opportunity.title}`)
})
// 🟢 HIGH 90/100 — Cloud Modernization for DoD
// 🟡 MED  62/100 — Data Processing for Treasury
// 🔴 LOW  25/100 — Building Renovation (NAICS mismatch)
